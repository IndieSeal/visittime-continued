# Visit Time
A webpage that counts the amount of time you've spent staring at it. All on a single line of code.

## Demo
Visit this webpage [here](https://kpoovakan.github.io/visittime). No setup required. Open the link and stare.

## Features
* Deciseconds
* Seconds
* Minutes
* Hours
* Days
* Page visits, stored locally

## For Developers
Visittime was going to be made into a winter-themed stopwatch of sorts, but this project has been discontinued. Developers are welcome to contribute to this project and bring it to its finish.
